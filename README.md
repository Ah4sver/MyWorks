
## Ключевые классы

| Класс              | Описание |
|--------------------|----------|
| **Coordinator**   | Центральный менеджер всего процесса. <br/>— Хранит очередь Map/Reduce задач <br/>— Выдаёт Worker'ам задачи через `synchronized + wait()` <br/>— Отслеживает прогресс через счётчики <br/>— После завершения Map-фазы создаёт Reduce-задачи <br/>— Уведомляет Worker'ов с помощью `notifyAll()` |
| **Worker**        | Исполнитель задачи (Thread). <br/>— Запрашивает задачу у Coordinator <br/>— Выполняет `task.execute()` <br/>— Завершает работу при получении `null` |
| **MapTask**       | Задача первой фазы. <br/>— Читает входной файл <br/>— Применяет Mapper <br/>— Разбивает слова по reduce-бакетам: `hash(word) % numReduce` <br/>— Создаёт промежуточные файлы `mr-X-Y.txt` <br/>— Отчитывается координатору о завершении |
| **ReduceTask**    | Задача второй фазы. <br/>— Читает все промежуточные файлы для своего reduceId <br/>— Группирует данные по ключам <br/>— Сортирует ключи <br/>— Применяет Reducer (подсчёт значений) <br/>— Пишет вывод в `output/mr-out-Y.txt` |
| **Mapper / Reducer** | Интерфейсы пользовательской логики. <br/>— **WordCountMapper**: разбивает текст на слова, нормализует, выдаёт пары (слово, "1") <br/>— **WordCountReducer**: суммирует значения списка ("1" + "1" + ...) |
| **KeyValue**      | Простая структура данных (ключ + значение) |

---

## 📂 Работа программы

При запуске `MyWorksApplication` происходит следующее:

1. Создаются 7 входных текстовых файлов (`file1.txt` … `file7.txt`).
2. Создаются директории:
    - `intermediate/` — промежуточные файлы map-фазы
    - `output/` — финальные файлы reduce-фазы
3. Запускаются worker-потоки.
4. Map-фаза создаёт файлы вида `mr-X-Y.txt`.
5. Reduce-фаза собирает и агрегирует данные в `mr-out-Y.txt`.
6. Программа завершает работу.
